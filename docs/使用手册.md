# 长卷作者使用手册

## 第一次打开

先按 [项目首页](../README.md#start) 安装依赖并构建前端，再运行 `.venv/bin/novel-agent serve --open`。macOS 也可以双击项目根目录的“启动长卷.command”。页面位于本机 127.0.0.1:8765。先进入左下角“模型与设置”，填写 DeepSeek 官方密钥，点击测试连接。连接测试查询供应商的模型列表，确认账户可访问当前代码配置的 deepseek-flash，不会生成正文。

预算是整个本地安装累计的费用估算上限，最高 300 元。启用语义检索时，首次下载中文嵌入模型需要网络；正文和索引仍存于此项目内。

## 建立能写下去的故事

“新建作品”中写清主角想得到什么、阻力来自哪里、能力边界和风格偏好。建议先用 8–12 章验证一个完整短卷，再扩展长篇。章数字段决定第一卷初始目录，每章字数是写作目标，不是输出保证。

进入“故事规划”，点击生成蓝图。规划员提出不同的冲突处理方式，再生成全书方向、章节目标、场景和十份记忆。确认之前不会替换正式设定。可以用“调整故事方向”修改方向和文风，先查看关联章节与十份记忆的影响预览，也可以编辑卷纲和章节计划；不要只写“打得精彩”，尽量写“谁为了什么，必须牺牲什么”。

每章计划包含视角、出场人物、冲突、行动代价、场景变化、必须遵守的设定和伏笔。作者确认的标题、目标和字数不会被上一章的自动记忆整理悄悄改掉。场景细节仍会根据已发生的故事衔接，作者可以再改。

写完一卷后可以创建新卷，系统参考现有记忆生成分卷提案，确认后更新前卷概述、本卷核心剧情与下一卷方向。分卷目录与章节号分别排序。

## 写作与修改

在左侧选择章节。预设目录写满或导入稿需要继续时，点击“新增章节”，在当前卷追加下一章，再编辑目标和场景。中间编辑器支持中文输入与 Markdown 基础排版。正文和标题修改后自动保存，也可按 ⌘S / Ctrl+S；未同步时本机浏览器保留草稿。不要同时在两个标签页编辑同一章，出现版本冲突时重新载入最新版本。

输入“本章创作要求”，点击创作本章即可看到真实流式文字。离开页面不会终止任务。右侧规划显示本章目标、约束和检索到的历史依据，点来源可回到对应章节。

选中一段正文，在下方填写要求后点击“改写选段”。改写先形成完整章节草稿，再重新审核和提取记忆。选段为空、重复不唯一或已经变化时，系统会要求重选。

右上角可切换专注模式与故事侧栏。窄窗口使用顶部章节下拉框。⌘K / Ctrl+K 打开故事搜索，Escape 关闭弹窗。

## 审阅与定稿

一致性编辑关注时间、知情、资源与规则；叙事编辑关注节奏、对话与表达。四维总分由程序按 30%、25%、25%、20% 加权计算。缺项、非法分数和空正文不会通过；严重问题阻止自动通过。原创性只是编辑风险判断，没有进行全网查重。

写作输入栏旁的“自动修订”可开关，并记住本机选择。关闭后仍由两位编辑审阅、提出记忆变化，正文修改由你决定；可以减少自动重写的等待和费用。默认开启，自动创作最多返工三轮。达到上限仍有问题时，保留稿件；作者可以修改正文重新检查，或填写原因后作出自己的定稿决定。

在“记忆”页逐项勾选接受的文档，展开差异可以修改更新后的全文。每条故事事实也能单独拒绝，并附有原文证据。请同时校正本章摘要；它会进入后续检索，并同步到目前剧情。请特别核对“推测”和“已知事实”的区别：引文存在不证明模型的解释一定正确。

点击“确认本章与记忆”后，正文、选择的记忆、事实、摘要和版本在同一数据库事务中保存。未接受的文档保持原状。定稿之后可以继续下一章。

如果在等待审阅时手动改正文，对应运行取消，旧评分和记忆提案失效。点击“检查与记忆提案”重新核对；不能用旧提案覆盖新稿。

## 版本与历史修订

“版本历史”可比较每个定稿版本与当前草稿。恢复历史版本只恢复为草稿，经过审核和确认后才形成新的正式版本。

修改历史章节定稿后，系统把受影响的后续章节标为待复核，旧事实和旧正文片段退出正式检索。请从最早的待复核章开始依次检查。系统使用该历史位置之前的记忆快照，避免把未来信息泄露给角色。

影响标记采取保守策略：历史章之后的定稿都会提示复核，不宣称自动理解每一条语义依赖。

## 暂停、失败与恢复

任务提示条可暂停或取消。暂停保留任务，恢复时从持久化检查点继续；正在模型调用时会在安全位置停止。取消释放作品的执行位置，原草稿与正式稿保留。

服务重启后，进行中的任务显示“已中断”；点击恢复。已完成的节点一般不会重复执行，但中断发生在模型调用途中时，该步骤可能重新请求，产生额外费用。正文提交已成功、检索重建未成功时，恢复只补齐后续工作。

网络、限流和格式错误会限次重试。错误状态展示可执行的处理建议，并保存运行记录。无法恢复的完整作者输出可使用“恢复已生成正文”；截断文本需要作者核对，不会冒充完整章节定稿。

## 导入、导出与备份

书架支持导入 ZIP：包含 workspace/十份中文记忆、小说本体/第X卷/第X章.md，可带 project.json。系统校验路径和大小，读取内容，不把不可信目录结构直接解压到磁盘。导入正文标记待复核，并保留原稿版本，从第一章重新核对以建立来源和状态。导入的记忆可能是全书末期状态，开始重审前请先校正主角初始状态、目前剧情并把后文标成计划。

在“导出作品”中点击格式卡片，文件保存到本工作目录的 data/projects/作品ID/exports，界面显示完整路径；不会自动写入其他目录。也可主动选择下方的浏览器下载链接。Markdown 或 TXT 用于阅读与投稿前整理，ZIP 保留原有中文文件目录。导出只含当前已定稿正文与记忆；未确认草稿、历史版本和运行记录需要保留本地数据库。

完整备份：停止服务，复制 data 目录。密钥另存于 .local/settings.json，权限为仅本机用户可读写；不要分享该文件或 .env。恢复时还原 data 后启动，缓存可重新建立。

## 阅读实验结果

“实验与洞察”分别展示整卷验证、机制探针、真实执行图压力验收和费用。匿名片段比较在两份整卷完成后出现，六组片段固定选自第 1、3、5、7、9、12 章开头。读完选择更愿意继续阅读的版本并填写原因；全部提交后才揭示版本身份。

自动编辑分、规则测试和你的阅读偏好分别记录，互不冒充。实验目前仅覆盖同一模型的一部玄幻短卷，不能证明对所有题材、所有作者或百万字长篇都有效。
