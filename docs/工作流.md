## 三个主要工作流详解

---

## 一、/start 初始化工作流

### 状态流转
```
IDLE → INIT_GET_DIR → INIT_GET_PROMPT → INIT_GENERATING → INIT_CONFIRM → (循环或结束)
```

### 流程图
```
┌─────────────────────────────────────────────────────────────────┐
│ 1. start()                                                       │
│    → 显示欢迎信息，等待用户输入目录                                │
│    state = INIT_GET_DIR                                          │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 2. _handle_dir(cmd)                                             │
│    用户输入目录路径（如 /Users/xxx/小说创作）                     │
│    → 创建 workspace/ 和 小说本体/ 文件夹                           │
│    → 调用 _create_memory_doc_templates() 创建模板文件            │
│    state = INIT_GET_PROMPT                                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 3. _handle_prompt(cmd)                                          │
│    用户输入小说总提示词（如"废柴修仙逆袭"）                        │
│    → 初始化文档列表（9个文档）                                    │
│    → 开始生成第一个文档                                           │
│    state = INIT_GENERATING                                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 4. _generate_current() 循环                                       │
│    for 每个文档：                                                 │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.1 _build_prompt(doc)                                  │  │
│    │    → 读取模板文件内容                                     │  │
│    │    → 收集已生成文档                                      │  │
│    │    → 组装提示词（InitPrompts.build_init_doc_prompt）    │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.2 _stream_generate(prompt)                           │  │
│    │    → 调用 AI 生成内容                                   │  │
│    │    → 流式输出到终端                                     │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.3 显示确认提示，等待用户输入                           │  │
│    │    用户输入：y/skip/redo/q                              │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.4 _handle_confirm(cmd)                               │  │
│    │    → y: 保存文档到 work_dir/doc.path                  │  │
│    │    → skip: 不保存                                      │  │
│    │    → redo: 重新生成                                    │  │
│    │    → q: 退出                                          │  │
│    │    → 保存进度                                          │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    current_doc_index++ → 下一个文档                             │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 5. _finish()                                                    │
│    → 显示完成信息                                                 │
│    state = READY                                                │
└─────────────────────────────────────────────────────────────────┘
```

### 初始化文档列表（9个）
1. 世界观
2. 主角形象状态
3. 本卷核心剧情
4. 下一卷剧情
5. 伏笔
6. 有关角色
7. 目前剧情
8. 事件
9. 当前章节设计规划

## 二、/new_volume 新卷创作工作流

### 状态流转
```
IDLE → NEW_VOLUME_GET_NUM → NEW_VOLUME_GENERATING → NEW_VOLUME_CONFIRM → (循环或结束)
```

### 流程图
```
┌─────────────────────────────────────────────────────────────────┐
│ 1. start(work_dir, novel_dir)                                   │
│    → 显示已有卷列表                                              │
│    → 等待用户输入卷编号                                         │
│    state = NEW_VOLUME_GET_NUM                                   │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 2. _handle_num(cmd)                                            │
│    用户输入卷编号（如 1、2）                                     │
│    → 创建卷文件夹 小说本体/第X卷/                               │
│    → 检查是否有前卷                                              │
│    → 设置要更新的文档：                                          │
│       有前卷：前卷剧情概述 + 本卷核心剧情 + 下一卷剧情           │
│       无前卷：本卷核心剧情 + 下一卷剧情                          │
│    → 开始生成                                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 3. _generate_current() 循环                                      │
│    for 每个文档：                                                 │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 3.1 _build_prompt(doc_name, doc_path)                 │  │
│    │    → 读取所有记忆文档（9个）                             │  │
│    │    → 组装提示词                                         │  │
│    │      (NewVolumePrompts.build_doc_prompt)               │  │
│    │    包含：记忆文档上下文 + 文档特定规则                  │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 3.2 _stream_generate(prompt)                          │  │
│    │    → AI 生成内容                                        │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 3.3 _handle_confirm(cmd)                              │  │
│    │    → y: 保存文档                                        │  │
│    │    → skip/redo/q                                       │  │
│    └─────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 4. _finish()                                                    │
│    state = READY                                                │
└─────────────────────────────────────────────────────────────────┘
```

## 三、/chapter 章节创作工作流（最复杂）

### 状态流转
```
IDLE → CHAPTER_GET_VOLUME → CHAPTER_GET_NUM → CHAPTER_GENERATING → CHAPTER_CONFIRM
     → CHAPTER_REVIEWING → CHAPTER_REVIEW_CONFIRM
     → CHAPTER_UPDATE_DOC → CHAPTER_UPDATE_CONFIRM → (循环9次) → 结束
```

### 流程图
```
┌─────────────────────────────────────────────────────────────────┐
│ 1. start(work_dir, novel_dir)                                   │
│    → 显示已有卷列表                                              │
│    → 等待用户输入卷编号                                         │
│    state = CHAPTER_GET_VOLUME                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 2. _handle_volume(cmd)                                          │
│    用户输入卷编号                                                │
│    → 检查卷文件夹是否存在                                        │
│    → 计算下一章编号                                              │
│    state = CHAPTER_GET_NUM                                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 3. _handle_num(cmd)                                             │
│    用户输入章节编号（直接回车用默认值）                          │
│    → 创建章节文件 第X卷/第Y章.md                                │
│    → 开始生成章节内容                                            │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 4. _generate_chapter_content()                                  │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.1 构建提示词                                          │  │
│    │    → 读取所有记忆文档                                    │  │
│    │    → 读取当前章节规划                                    │  │
│    │    → 读取上一章内容（用于衔接）                          │  │
│    │    → 组装提示词                                         │  │
│    │      (ChapterPrompts.build_chapter_prompt)             │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.2 _stream_generate(prompt)                          │  │
│    │    → AI 生成章节内容                                    │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 4.3 显示章节确认提示                                    │  │
│    │    state = CHAPTER_CONFIRM                             │  │
│    └─────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 5. _handle_confirm(cmd)                                         │
│    用户输入 y/skip/redo/q                                        │
│    → y: 保存章节内容到文件                                      │
│    → skip: 不保存                                              │
│    → redo: 重新生成章节                                        │
│    → q: 退出                                                   │
│    → 重置审核器                                                 │
│    → 进入审核流程                                                │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 6. _do_review()                                                 │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 构建审核提示词（4个维度）                                │  │
│    │ • 剧情一致性（30%）                                     │  │
│    │ • 文笔流畅度（25%）                                     │  │
│    │ • 人设吻合度（25%）                                     │  │
│    │ • 原创性（20%）                                         │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ AI 审核，返回结果：                                     │  │
│    │ • passed: 是否通过                                     │  │
│    │ • scores: 各维度评分                                   │  │
│    │ • reason: 未通过原因                                   │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ _show_review_confirm_prompt()                          │  │
│    │ 显示审核结果，等待用户输入                               │  │
│    │ state = CHAPTER_REVIEW_CONFIRM                         │  │
│    └─────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 7. _handle_review_confirm(cmd)                                  │
│    用户输入 y/redo/q                                             │
│    → y: 继续更新记忆文档（最多3轮返工）                         │
│    → redo: 重新生成章节                                         │
│    → q: 退出                                                    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 8. _start_update_memory_docs()                                  │
│    设置要更新的文档列表（9个），从第一个开始                      │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 9. _generate_memory_doc() 循环（9次）                           │
│    for 每个记忆文档：                                             │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 9.1 _build_memory_doc_prompt(doc_name, doc_path)       │  │
│    │    → 读取当前文档内容                                    │  │
│    │    → 读取刚创作的章节内容                                │  │
│    │    → 读取所有记忆文档                                    │  │
│    │    → 组装提示词                                         │  │
│    │      (ChapterPrompts.build_memory_doc_prompt)          │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 9.2 _stream_generate(prompt)                           │  │
│    │    → AI 生成更新后的文档内容                             │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    ┌─────────────────────────────────────────────────────────┐  │
│    │ 9.3 _handle_update_confirm(cmd)                        │  │
│    │    → y: 保存文档到 work_dir/doc_path                  │  │
│    │    → skip: 不保存                                      │  │
│    │    → redo: 重新生成                                    │  │
│    └─────────────────────────────────────────────────────────┘  │
│                              ↓                                    │
│    current_doc_index++ → 下一个文档                            │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│ 10. _finish()                                                   │
│     显示完成信息                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 记忆文档更新顺序（9个）
1. 世界观 - 从章节提取新设定追加
2. 主角形象状态 - 更新心理/处境/目标
3. 本卷核心剧情 - 添加已完成事件
4. 下一卷剧情 - 检查是否需要调整
5. 伏笔 - 回收/新埋伏笔
6. 有关角色 - 新角色/状态变化
7. 目前剧情 - 添加本章，删除最旧
8. 事件 - 主线完成/新事件
9. 当前章节设计规划 - 标记完成+设计下一章

## 对比总结

| 特性 | /start | /new_volume | /chapter |
|------|--------|-------------|----------|
| 用户输入 | 目录 + 小说提示词 | 卷编号 | 卷编号 + 章节编号 |
| 生成文档数 | 9个 | 2-3个 | 9个（记忆更新） |
| 是否审核 | 否 | 否 | 是（4维度，≤3轮） |
| 是否保存进度 | 是 | 是 | 是 |
| 关键数据 | user_prompt | volume_num | volume_num, chapter_num |
