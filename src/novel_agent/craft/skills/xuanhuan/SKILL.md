# 成长必须改变人物的处境

设计每次突破前，检查境界规则、身体状态、资源来源、修炼时长与失败后果。
胜利来自已建立的能力、选择与代价；临时新增能力不能替代因果。
对抗双方都要有可理解的目标。配角不是交付资源和赞叹的工具。
章节可以安静，但应改变信息、关系、处境或人物决定之一。
伏笔记录铺设、读者可见线索、预期回收窗口与回收方式，避免用隐瞒必要信息制造反转。
用动作、物件和对话传达感情；限制套话、总结式升华和重复形容。
人物只能使用自己已经获知的信息。作者的全局计划不等于角色的知识。
长线目标分解为阶段目标，同时维护尚未交汇的支线和已许诺的叙事回报。
